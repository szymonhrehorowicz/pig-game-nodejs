# Pig Game Node.js
Simple project of a pig game made with Express Node.js
## See online
App is running on Google Cloud servers under this link: https://pig-game-node.appspot.com
### Build with
* [Node.js](https://nodejs.org/en/)
* [Express](https://expressjs.com/)
<bt />
NPM Plugins:
* [express-handlebars](https://www.npmjs.com/package/express-handlebars)
* [express-validator](https://express-validator.github.io/docs/)
<br />
Also used:
* [Bootstrap](https://getbootstrap.com/) - some of the classes
